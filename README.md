## 📊 Time Complexity

| Collection | Search | Insert | Delete |
|------------|--------|--------|--------|
| ArrayList | O(n) | O(1)* | O(n) |
| LinkedList | O(n) | O(1) | O(1) |
| HashSet | O(1) | O(1) | O(1) |
| TreeSet | O(log n) | O(log n) | O(log n) |
| HashMap | O(1) | O(1) | O(1) |
| TreeMap | O(log n) | O(log n) | O(log n) |

> *Amortized Complexity
